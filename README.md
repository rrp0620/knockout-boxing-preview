# Knockout Boxing site

Static site (HTML/CSS/JS, GSAP from CDN), published via GitHub Pages from main root.

- Pages: index.html and the other *.html files at root
- Hero: scroll-scrubbed image sequence in img/seq/, settings in the CONFIG block of main.js
- Generator: _source/build.py produces the HTML pages. Edit and rerun it instead of hand-editing generated HTML.
- Before launch: switch canonical, sitemap.xml and Open Graph URLs from the github.io preview to the real domain.
